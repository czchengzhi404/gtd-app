## 十、本次测试发现的严重问题（已修复）

**写操作全部失效**：新建任务、完成任务、保存正文都会静默失败（界面不崩，部分有 toast）。

根因：`createExpoExecutor` 的 `transaction` 用同步 `execSync` 开事务却 `await` 异步函数，并发时两个事务交错，expo-sqlite 原生层抛 `NullPointerException`。

修复：事务串行队列（v2.5.3）。已验证：新建 ✅、完成 ✅、正文保存 ✅、状态切换 ✅。
