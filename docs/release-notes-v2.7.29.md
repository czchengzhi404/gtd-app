# v2.7.29 · 最终版：移除诊断日志

## 这一版做了什么

只移除 `addPrereq` 里为排查而加的三行 `console.warn`，恢复成
成功/失败 toast 的简洁形态。**不改任何业务逻辑、不改动数据层。**

v2.7.28 已用 6/6 设备验证确认「设好先后」全链路通了：

```
[dep] ok records=1 returned=["01a1dcf9-…"]
PASS  前置 chip 出现在详情页（WAITING ON | Alpha）
PASS  首屏出现「另有 N 件在等前置完成」
7 left today → 6 left today   ← 被挡住的任务从「现在」消失
```

## 为什么单独发一版

v2.7.28 的 tag 指向的是**带诊断日志**的代码。日志无害，但让 APK
与源码树不完全一致。本版让两者对齐，桌面交付包用这一版。
