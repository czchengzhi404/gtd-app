## 一、项目「切换类型」是什么

`project.kind` 有两个值：

| 类型 | 含义 | 适用 |
|---|---|---|
| **sequential（顺序）** | 一次只推进一件事。完成当前任务后，下一个才成为「下一步行动」出现在今天页 | 有先后依赖：装修、发布流程 |
| **parallel（并行）** | 多个任务可同时推进，各自独立 | 无依赖：三篇文章、多个客户 |

**当前 UI 只是标签，点不动**。数据层 `project.upsert` 支持 `kind`，但详情页没给切换入口——属于「假已实现」，待补。

## 三、v2.6.0 修了什么

### 启动崩溃根因

从 v2.5.3 起反复出现的：

```
NativeDatabase.execSync has been rejected → NullPointerException
```

**根因**：expo-sqlite 的 API 全是**同步**的，而命令 handler 是 **async**。v2.5.3 只串行化了 `transaction`，`query` 和 `run` 还在队列外——启动时 `migrate()` 在事务里，`getKvValue()` 在外面读，两个调用撞上就崩。

**修复**：`query` / `run` / `transaction` **全部进同一条 Promise 队列**；事务内部用直连 executor（不再入队，避免死锁）。

### 同步开关不落库

开关只改本地 state → 同步服务从库里读到 `enabled: false` → 提示「同步未启用」。已改成开关切换即落库 + 同步前自动保存。
