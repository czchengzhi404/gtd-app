## 为什么改

之前的 token 文件自称「纸与墨 Calm Productivity」，但实际是
**暖白底 + 宝蓝主色 + 通用圆角卡片**：每个组件单看合格，但没有一处视觉选择在替
「只看现在能做的事」这个主张干活。这正是模板感的来源。

## 改了什么

### 1. 主色：宝蓝 → 赭石

| token | 改前 | 改后 |
|---|---|---|
| primary（亮） | `#1D4ED8` 宝蓝 | `#8C3D0B` 赭石 |
| primary（暗） | `#8FA8FF` | `#E0A878` |
| info（亮） | `#0B6AA8` | `#1D4ED8`（宝蓝降级为链接/信息色） |
| surface | `#FFFFFF` 纯白 | `#FFFDF9` 微暖白 |
| focusRing | 蓝 | 赭 |

蓝在暖白纸底上永远读作「屏幕色」，压不住纸感。深色模式下 `textOnAccent` 跟
`onPrimary` 统一为深墨（对比度测试抓到过 1.92:1，已修）。

### 2. 首屏：从 40 条列表变成「一张」

```
11月13日 · 周四                    今天还剩 4 件
┃
┃  现在
┃  ┌──────────────────────────────────┐
┃  │  预约体检                          │   ← 32px 标题，全屏唯一大卡
┃  │  今天 18:00                        │
┃  │                      [ 完成 ✓ ]   │   ← 唯一实心按钮
┃  └──────────────────────────────────┘
┃
┃  之后 · 3 件                          ← 灰字，不套卡片
┃  · 量书房尺寸
┃  · 回复客户邮件
┃  · 整理桌面
┃
┃  查看全部 4 件 →
```

只有当前卡有底和边框，其余全靠字号与留白。左侧竖脊 = 装订线，与已做的
写作页左边线同语言。

### 3. `pickNextAction()`：谁配当「现在这一件」

纯函数 + 10 项单测。规则：
1. 排除已完成 / 软删 / 推迟到未来
2. **排除还有未完成前置的**（`blockedBy`，即 NextTodo 的先后关系）
3. 逾期 → 今天 → 未来 → 无日期
4. 同级：有优先级压过无优先级（0 视为「无」而非「最高」），再按 orderKey

前置指向不存在的 id 时保守挡住，宁可少显示也别漏做。

### 4. 不删任何既有能力

- 「一张 / 全部」用 PageHeader 图标切换，写进 kv `inbox.focusMode`
- **筛选/搜索一生效就自动回到「全部」**：用户主动筛选就是想看列表，硬收成一张是帮倒忙
- 多选 / 拖拽模式下也自动回「全部」
- 快速添加永远在，位置不变（捕捉不能被首屏改造挤掉）
