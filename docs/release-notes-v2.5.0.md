# v2.5.0 · 能写字了

这一版把「任务清单」补成了**能写正文的地方**。

## 新增

### 写正文
- 详情页正文区支持「查看 / 编辑」双模式：多行输入、实时字数、未保存退出二次确认
- 字数统计：中文按字、英文按词（`don't` / `state-of-the-art` 不拆词），emoji 不虚高
- 显示「N 字」「约 N 分钟读完」；项目详情显示「共 N 字」

### 找得到
- 搜索支持**多词 AND**（`雨 比喻` 可跨标题/正文/标签/情境命中）
- 搜索范围可限定：全部 / 标题 / 正文
- 输入防抖 250ms，长库输入不再发涩

### 写得顺
- Markdown 支持**有序列表**与**缩进层级**（2 空格一层，最多 4 层）
- 专注时长可选 25 / 45 / 90 分钟（写作者需要深度块）
- 素材库：`someday` 条目集中查看，带条目数 / 有正文数 / 总字数
- 写作统计：每日字数曲线（今日新增、近 14 天、总字数、连续天数）

### 不丢稿
- 正文版本历史：每次保存前自动留旧版，每任务保留 20 条，可一键恢复
- 导出补强：
  - 到期**时刻**保留（18:00 的「只写日期」约定仍输出纯日期）
  - 修掉 `📅` 残留在标题里的往返 bug
  - 数据页新增「仅未完成 / 含已完成」
  - 详情页新增「导出正文」

## 性能

| 项目 | 变化 |
|---|---|
| 全库字数统计（2000 任务） | 13.50 ms → **0.08 ms**（≈169×） |
| 附件收集 | **801 次查询 → 1 次** |
| 搜索（单词 / 双词） | 1.71 / 2.68 ms → **1.04 / 1.22 ms** |
| 列表 | 行级 `React.memo` + 原生 `FlashList` |
| 同步推送 | 内容无变化时跳过写 `records.json` |
| 大库 | 新增分页 API（`getTasksPage` / `countTasks`，默认未启用） |

## 已知问题

- **FlashList 未在真机验证**：本机无法构建 Android。若滚动或编辑出现异常，删掉 `TaskList` 里的 `Platform.OS !== "web"` 分支即可回滚到 `FlatList`。
- 数据库分页默认关闭：同步合并、搜索、统计仍以「store 是全量」为前提。
- 同步仍是全量快照（只是没变就不传），协议级增量未做。

- 数据库迁移到 **v7**（新增 `note_versions` 表）。升级自动执行，无需操作。
