# v2.7.15 · 新建的空分区要能看见

## 问题

v2.7.14 刚把「项目分区」补上 UI，实测就发现一个直接劝退的细节：

新建分区后，项目页**什么都没变**。

原因在渲染层：

```tsx
groups.map((group) => {
  if (group.items.length === 0 && group.title !== null) return null;  // ← 空分区被跳过
```

「没有任务的分区」被整组丢掉。而新建的分区必然没有任务——于是用户点完「新建分区」，
输入名字、确认，界面上一点反馈都没有，只能以为失败了。

紧接着的第二重伤害：既然看不到分区，也就不知道该去哪里把任务放进去。

## 改法

空分区照常渲染标题，下面显示「还没有任务」的提示（该文案 `project.groupEmpty` 本来就有，
之前只用于「未分组」那一段）：

## 仍未解决

**设备列表在移动端没有 UI**。同步页到 `Save config` 就结束，`Devices` 区块只在桌面端有。
服务端明明已经有设备数据（manifest/records 都传上去了），手机上却看不到「有哪些设备在同步」，
也没法判断「另一台设备的数据是不是已经进来了」。这是一处真实的功能缺口，需要单独补。
