# v2.7.36 · 横屏侧栏与底部内容避开系统安全区

## 在 v2.7.35 上实际复现

此前窄屏证据只改变过密度，截图仍为 1080×2400，不能据此声称做过 375dp 回归。

本轮在 Android 模拟器设置 750×1624、320dpi，并读取 `am get-config`：

- 竖屏：`w375dp-h812dp`，原始截图 750×1624。
- 横屏：`w812dp-h375dp`，原始截图 1624×750。

375dp 竖屏的主要操作区没有挤出左右边界，长标题可以换行。横屏会按现有 ≥768dp 断点切换到侧栏布局，此时暴露出两处问题：

1. 侧栏没有顶部安全区，品牌图标与状态栏时间相碰。
2. 宽屏容器没有底部安全区，滚动内容会绘制到系统手势导航区域，完成按钮可与手势条重叠。

复现截图和显示参数保存在 `android-report/responsive-v2735/`。

## 局部修复

宽屏布局的原生安全区：

- 宽屏容器使用当前的左右、底部 insets，避开系统手势区域和横屏侧边遮挡。
- 侧栏单独增加顶部安全区。
- 页面本来已有自己的顶部 inset，因此不再给整个内容区重复加顶边距。
- Sidebar 的额外样式为可选参数，未传时保持桌面端既有行为；竖屏仍使用原来的底部导航布局。

另外，在第一个候选包上实际打开横屏软键盘，发现键盘上沿约 254px，而添加按钮下沿约 277px：按钮有一部分被遮住。修复为在键盘显示且视口较矮时临时收起标题操作区，让快速添加完整露出；收起键盘后标题恢复。快速添加组件始终保持挂载，字段和提交逻辑不变。

保留既有导航数量、任务排序、字号、配色及数据写入路径。超出横屏可视高度的内容仍通过正常的纵向滚动访问。

`android-report/responsive-v2736/` 还保留了第一候选的负向证据：旧代码品牌文字从 `32px` 开始而状态栏下沿是 `48px`；键盘出现时添加按钮下沿约 `277px`，键盘上沿约 `254px`。这两个失败都被修复后，第二候选才达到 22/22。
