# v2.7.22 · 《纸与当下》收尾（减法）

## 第二轮改了什么

只有一处：首屏 `Process` 的 ghost 按钮传 `tone="default"`，文字从赭色改为墨色。

v2.7.21 把 `Process` 从实心按钮降为 ghost 后，`Button` 的 ghost 变体默认
`fg: colors.primary`，于是它变成**橙色文字**，仍和 `Done` 抢色。
没有去改 `primitives.tsx` 的全局默认值（那会动到所有页面的 ghost 按钮），
只在首屏这一个调用点指定 `tone="default"` → 用 `colors.text`。

至此整屏**赭石只出现在**：一道短笔迹 + `Done` 一个实心按钮。brief 的
「唯一笔迹 / 唯一主按钮」终于成立。
