# v2.7.35 · 深色模式：状态栏和原生导航栏跟随应用主题

## 实际复现

在 v2.7.34 签名 APK 上，让 Android 保持浅色、在应用设置里选择深色：

- 首页背景变成深色，但系统时间、电量仍显示黑色，难以辨认。
- 任务详情内容是深色，原生 Stack 标题栏仍是白底黑字。
- 完成测试任务后，撤销条能出现，点撤销也能恢复原任务；这一条行为没有坏。

复现截图保存在 `android-report/dark-v2734/`。这不是新增视觉方向，而是补齐应用内主题与系统栏、导航栏的接线。

## 修复

`useThemeSettings()` 增加只读的 `colorScheme`（最终生效的 light/dark），保留原有 `mode` 和字体偏好。

根布局中的状态栏和 Expo Router 导航主题都消费这个结果：

- 应用选深色时，状态栏使用浅色文字。
- 应用选浅色时，状态栏使用深色文字。
- 应用选跟随系统时，以上两者随系统变化。
- 原生标题栏使用应用的 `surface`、`text` 和 `border`；保留导航主题原有字体等字段。

所有主题 Hook 都在应用 ThemeProvider 下无条件调用，没有改变启动、迁移、数据写入或路由结构。

## 文字对比度

深色 `textTertiary` 在 `surfaceMuted` 上原为 4.293:1。标签输入框等位置会把它用于普通字号的占位文字，因此不能仅因它是次要文本就放宽到 3:1。

把深色 `textTertiary` 从 `#8A857C` 调为 `#928D84` 后，同一背景上的对比度为 **4.772:1**；浅色 token 没有修改。

测试对两套主题都按 4.5:1 检查正文、辅助文字、视角切换、首屏链接、当前底栏入口和角标数字等实际配对。并未据此宣称所有控件、边框或整个应用达到完整无障碍合规。
