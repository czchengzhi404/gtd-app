# v2.7.16 · 视觉：启动屏配色、勾选回弹、项目色点、写作纸感

按「用户真正会遇到的时刻」改的四处，不是泛泛的换皮。

## 1. 启动屏：三个颜色互不搭，而且对勾几乎看不见

改之前是这样：

| 位置 | 颜色 |
|---|---|
| 启动屏背景 | `#208AEF`（亮天蓝） |
| 应用主色 | `#1D4ED8`（深宝蓝） |
| 页面底色 | `#F7F5F1`（暖白） |

开 App 的体验是：**刷一下亮蓝全屏 → 立刻跳成暖白页面 + 深蓝按钮**，两次跳色。

更糟的是 `splash-icon.png` 本身是一枚**浅蓝对勾 + 白色卡面**——它本来就是给浅色背景画的。
把浅蓝对勾压在亮蓝底上，勾和底几乎一个色，等于什么都没有。

改了两处：

- 底色调成画布色 `#F7F5F1`，与首屏无缝衔接
- 对勾重映射成主色 `#1D4ED8`（`bench/recolor-splash-icon.py`，保留原有明暗与柔和阴影，原图备份为 `splash-icon.original.png`）
- 图标尺寸 76 → 96，在暖白底上不至于显得太小

## 2. 勾选瞬间的回弹

列表增删本来就有 220ms 收拢动画（`TaskList` 的 `LayoutAnimation`），但**复选框自己是硬切**——
填色、出现对勾，一帧到位。

勾选是一天里最高频的动作。加了 0.86 → 1 的 spring 回弹（`friction: 4, tension: 180`，native driver），
让「我确实勾掉了」有一点身体记忆，而不是屏幕默默少了一行。

只有 30 行代码，动的是最值钱的那个瞬间。

## 3. 项目色点：一眼分开两个项目

项目列表此前是纯文字 + 灰色 `Sequential`/`Parallel` 徽章，「装修」和「军师欠下的999件事」长得一样。

现在每个项目名字前有一个 9px 色点。

**没有加数据库字段**——颜色由项目 id 派生（`projectAccent()`，FNV-1a 散列取 6 色之一）。
理由：做成用户可选色要给 `projects` 表加列、写迁移、还要改同步的字段合并策略，
成本远大于收益；而「一眼区分」这个需求，派生一个稳定色就够，
而且同一个项目在任何设备、任何时刻都是同一个颜色。

## 4. 写作页的「纸感」

正文是核心功能（有字数、阅读时长、版本历史），但之前和普通文本框没区别。

- 编辑区左侧加了一条 1.5px 的竖线（`primaryMuted`），像横格本的左边线
- 行距 26 → **30**（约 1.9 倍），`letterSpacing: 0.2`，长文不容易串行
- 只读态行距 22 → 26

**没有铺纸张纹理图片**：那会让整个 App 变闷，而且和现在这套暖白卡片的气质冲突。

## 更正一处我上一轮说错的

上一轮分析里我把「空态插画」和「tab 选中态」列成了缺口，实际上：

- 空态**已有**分层插画（56px 圆形底 + 右上角主色徽章，5 种变体）
- tab 选中**已有**独立色块 + 主色 + 加粗标签

这两处不是缺口，这一版没动。
