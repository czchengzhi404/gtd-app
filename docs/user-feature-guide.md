# GTD 清单 · 推荐功能指南（v2.0 用户版）

> 适用版本：v2.0.0（Android / Windows / macOS / Linux）
> 读者：第一次用、或用了很久但只用了 10% 功能的人
> 目标：**用最少的操作，把「脑子里的事」变成「可靠的下一步」**

---

## 0. 这份文档怎么用

- 只想快速上手 → 看 **§1 三十秒上手** + **§8 一页版**
- 想榨干功能 → 看 **§2 十个最值得用的功能**
- 有具体场景（换手机、备份、导入旧数据）→ 看 **§3 场景推荐** 和 **§6 FAQ**
- 记不住语法 → 看 **§4 快捷操作速查**（建议截图存手机）

一条使用原则先放在前面：

> **收集箱只负责「记」，不负责「做」。** 每天花 3 分钟把收集箱理清，这个 App 才开始产生价值。

## 1. 三十秒上手

装好之后，先做这三件事（顺序别反）。第一次打开会看到三屏引导，看完可以直接跳过——它说的就是下面这三件事：

| 步骤 | 做什么 | 在哪 |
|---|---|---|
| ① | 随手记 3 条今天脑子里的事（不用管格式） | 收集箱顶部输入框 |
| ② | 点右上角「**理清**」，把 3 条逐条处理掉 | 收集箱 → 理清 |
| ③ | 给其中 1 条加上到期时间（比如「明天」），去「今天」看它出现 | 任务详情 / 快速添加语法 |

做完这三步，你已经跑通了 GTD 的最小闭环：**捕获 → 理清 → 执行**。

## 2. 十个最值得用的功能

### ① 随手记：一句话带出时间、情境、优先级

**价值**：不用点开表单，一行字就是一条完整任务。

**怎么用**：在收集箱输入框直接写，例如

```
给张总发周报 #工作 @电脑 !! 明天 下午3点 +本周
```

会被自动解析成：标题「给张总发周报」、项目「工作」、情境「电脑」、优先级 P2、明天 15:00 到期、标签「本周」。

**小技巧**：
- 只写 `明天` 不写时刻 → 默认 **18:00** 到期；
- 想标「等别人」→ 写 `>张三`，任务会自动进「等待中」；
- 不知道怎么写？先随便写，理清时再补。

---

### ② 理清收件箱：把「一堆事」变成「能做的事」

**价值**：GTD 里最容易跳过、也最关键的一步。它会逐条问你：这条要做什么？

**怎么用**：收集箱 → 右上角「**理清**」。页面会：
1. 一次只显示一条，给出**建议动作**和一句理由（例如「建议：下一步行动 — 它没有明确项目，也不需要 2 分钟内完成」）；
2. 你点一个动作即可：下一步 / 等待 / 将来也许 / 完成 / 2 分钟做掉 / 委派 / 转项目 / 推迟 / 删除；
3. 处理完自动跳下一条，顶部有进度。

**小技巧**：
- 标题里带 `2分钟`（或标签写 `2min`）会被识别为「2 分钟任务」，直接建议你立刻做掉；
- 桌面端支持 `1`–`9` 直接触发动作、`←/→` 切换条目；
- 建议只是建议，你可以不采纳。

---

### ③ 今天 + 专注：只看「现在该做什么」

**价值**：任务一多就会焦虑，这两个视图负责把范围缩小。

- **今天**：今天到期 + 已逾期的任务；被「推迟」的任务到时间会自动出现。顶部可切 **列表 / 即将 / 日历 / 时间线**（时间线需宽屏）；
- **专注**：你手动「选入专注」的下一步行动 + 今日到期，再配一个 **25 分钟番茄钟**。

**怎么用**：
- 任务详情 → 「**☆ 选入专注**」；
- 专注页 → 「开始」跑番茄钟，结束会提示休息。

**小技巧**：每天只选 **3 条**进专注。选 10 条等于没选。

---

### ④ 项目：给「多步才能完成的事」一个容器

**价值**：单条任务装不下「装修」「上线新版本」这种多步目标。

**怎么用**：
- 项目页 → 「＋ 新建项目」；
- 项目分**顺序**（一次只推进第一个未完成项）和**并行**（多条同时推进）；
- 项目详情可在**列表**和**看板**之间切换；看板里长按拖动卡片即可改状态；
- 项目详情里会高亮「**下一步行动**」——这就是你真正要做的动作；
- 可以用「区域」把项目分成 工作 / 生活 / 学习。

**小技巧**：项目名写「结果」，任务名写「动作」。
✅「上线 v2.0」→ 下一步「写发布说明」
❌「上线的事」→「搞定上线」

---

### ⑤ 任务模板：把「每周都要做的事」存成骨架（v2 新增）

**价值**：周报、复盘、出差清单、客户拜访……每次都从头写太浪费。

**怎么用（两种）**：
1. **从已有任务生成**：打开一条做得很标准的任务 → 操作区点「**另存为模板**」→ 起个名字；
2. **手动新建**：更多 → 洞察 →「**模板**」→ 右上角 ＋ → 填模板名和任务标题。

之后在模板页点「**用这个模板新建任务**」，就会生成一条带好标题/笔记/优先级/项目/情境/标签/清单/重复规则的新任务。

**注意**：模板只存**骨架**，不带日期和完成状态——日期每次新建时再定，避免"模板里的日期永远是旧的"。

---

### ⑥ 撤销：手滑删错了，Ctrl+Z 救回来

**价值**：删除、批量完成、批量移动都可以回退。

**怎么用**：
- 操作后底部出现提示条，点「撤销」；
- 桌面端直接 `Ctrl+Z`（macOS 为 `⌘Z`）；
- 提示条上如果显示「还可撤销 N 步」，点它可以打开**撤销历史**，一次撤销一步或全部撤销。

**规则**：最多保留 **10 步**，**60 秒**内有效。超过就别指望了——重要数据请用备份。

---

### ⑦ 搜索：找得到，才敢记

**两个入口，用途不同**：

| 入口 | 适合 | 怎么打开 |
|---|---|---|
| **命令面板** | 手不离键盘，快速跳转/新建 | `Ctrl+K`（macOS `⌘K`） |
| **全局搜索页** | 认真找东西（跨任务/项目/笔记/标签） | 更多 → 洞察 →「全局搜索」 |

搜索会高亮命中词，并标出命中位置（标题/笔记/标签/情境）；找不到时可以直接用关键词新建任务。

---

### ⑧ 统计 + 四象限：知道自己在往哪走（v2 新增）

**统计面板**（更多 → 洞察 →「统计面板」）：
- 7 天 / 30 天完成数、7 天完成率、连续完成天数；
- 近 14 天完成趋势柱状图；
- 每个项目的完成进度、每个情境下的未完成数量。

**四象限**（更多 → 洞察 →「四象限」）：
- 自动把任务分到「重要且紧急 / 重要不紧急 / 紧急不重要 / 既不重要也不紧急」；
- 判定规则：重要 = P2 以上 / 星标 / 挂着项目的到期任务；紧急 = 48 小时内到期或已逾期。

**小技巧**：每周看一次「重要不紧急」——这里才是真正决定你半年后状态的事。

---

### ⑨ 导入导出：数据是你的，随时能带走

**导出**（更多 → 数据）：导出时手机上会让你选「保存到手机文件夹」或「分享给其他应用」——
保存会写进你挑的目录（文件管理器里能看到），分享则交给微信/邮件/网盘。

| 格式 | 用途 |
|---|---|
| JSON | 完整备份 / 换设备 / 迁移到别的工具 |
| Markdown | 贴进笔记软件、发给同事、打印 |
| ICS | 导入系统日历 / Google Calendar / Outlook |

**导入**（更多 → 数据 →「导入 Markdown / Todoist」）：
- 支持 **Markdown 复选框清单**（`- [ ] 任务`，`# 标题` 当项目）；
- 支持 **Todoist CSV**、**TickTick CSV**；
- 支持任意 CSV（页面上选格式即可），优先级 P1–P4 / 高中低 会自动映射。

**小技巧**：粘贴导入前会先给预览（多少条任务、多少个项目、跳过几行），确认无误再点导入。

---

### ⑩ 同步与备份：手机记、电脑做（可选）

**同步**（更多 → 同步）：支持 **坚果云 / 任意 WebDAV / S3 兼容存储 / 桌面本地文件夹**。
- 不需要注册账号，填自己的网盘即可；
- 多设备按「谁改得晚谁生效」合并，冲突会记在同步日志里；
- 不配置同步也完全能用，数据只在本机。

**备份**：
- **桌面端**：每日自动本地备份，保留最近 7 份，可一键恢复（更多 → 数据 → 本地备份）；
- **手机端**：没有自动备份，建议每周「导出 JSON」存到网盘或电脑。

## 3. 按场景推荐

### 场景 A：早上 3 分钟开机

1. 打开「今天」看有没有逾期（红色竖条）；
2. 逾期的：要么今天做，要么改期，不要留着；
3. 从「下一步行动」里挑 3 条 → 选入专注；
4. 开始第一个番茄钟。

### 场景 B：开会/走路时突然想到事

- 手机：桌面小组件/快捷方式打开 App → 收集箱输入框一句话；
- 桌面：`Ctrl+Shift+Space` 全局快速收集，不打断当前工作；
- 链接直达：`gtd://add?title=买牛奶`。

### 场景 C：周日晚 15 分钟回顾

更多 → 今日回顾 →「开始每周回顾」，六步走完：
收集箱清空 → 每个项目有没有下一步 → 未来两周日程 → 等待中的催一下 → 将来也许翻一翻 → 本周完成了什么。

页面顶部还会列：**该回顾的项目**（按你设的回顾周期）、**长期未推进的项目**、**近 8 周完成趋势**、**整体进度**——先看这几块，再进六步。

### 场景 D：换手机 / 重装

1. 旧机：更多 → 数据 →「导出全部数据（JSON）」，发给自己；
2. 新机：更多 → 数据 →「从 JSON 导入（合并）」；
3. 如果配了同步：新机填同样的同步配置，点「立即同步」即可。

### 场景 E：担心数据丢

- 开同步（推荐坚果云/WebDAV，免费额度够用）；
- 桌面端保持自动备份；
- 手机端每周导出一次 JSON；
- 三件事做两件，基本不会丢。

## 4. 快捷操作速查

### 4.1 快速添加语法（可混排，顺序随意）

| 写法 | 效果 |
|---|---|
| `@电脑` | 情境（在哪做） |
| `#工作` | 归入项目「工作」（没有会自动建） |
| `+本周` | 标签 |
| `!` / `!!` / `!!!` | 优先级 低 / 中 / 高 |
| `>张三` | 等待某人（自动进「等待中」） |
| `今天` `明天` `后天` | 到期日（默认 18:00） |
| `周五` `下周一` | 本周/下周对应日 |
| `3天后` | 相对日期 |
| `10月1日` `2026-10-01` | 绝对日期 |
| `下午3点` `15:30` `3pm` | 指定时刻 |
| `每天` `每工作日` `每周一三` `双周` | 重复 |
| `每月15日` `每月最后工作日` `每年10月1日` | 重复 |
| `每隔3天` `完成后3天` `重复5次` | 重复细节 |
| `2分钟`（写进标题） | 理清时建议「立刻做掉」 |

### 4.2 手势（手机）

| 手势 | 效果 |
|---|---|
| 左滑任务 | 完成（可撤销） |
| 右滑任务 | 延后到明天 9:00（可撤销） |
| 长按任务 | 进入多选（批量完成/删除/移动） |
| 长按拖动手柄 | 列表内排序 |
| 长按拖动看板卡片 | 跨列改状态 |
| 点行尾 `⋯` | 打开动作面板 |

### 4.3 桌面快捷键

| 快捷键 | 效果 |
|---|---|
| `Ctrl/⌘ + N` | 新建任务 |
| `Ctrl/⌘ + K` | 命令面板 |
| `Ctrl/⌘ + Shift + K` | 快速收集 |
| `Ctrl/⌘ + Shift + Space` | 全局快速收集（任何窗口） |
| `Ctrl/⌘ + F` | 搜索 |
| `Ctrl/⌘ + Shift + F` | 专注 |
| `Ctrl/⌘ + Shift + R` | 每周回顾 |
| `Ctrl/⌘ + Shift + S` | 立即同步 |
| `Ctrl/⌘ + Shift + B` | 立即备份 |
| `Ctrl/⌘ + Z` | 撤销上一步 |
| `↑ / ↓` `Enter` `Esc` | 列表与面板导航 |

### 4.4 桌面增强

- **系统托盘**：关闭窗口不退出，点托盘图标随时回来；
- **原生右键菜单**：任务上右键，直接改状态/专注/完成/删除；
- **原生通知**：每日到期概览 + 精确时刻提醒（到期后 5 分钟内触发，单轮最多 5 条）。

## 5. 推荐设置

| 设置 | 推荐值 | 为什么 |
|---|---|---|
| 主题（更多 → 设置） | 跟随系统 | 白天黑夜自动切，不刺眼 |
| 字体 | 默认系统字体 | 霞鹜文楷好看但占 19MB，按需再开 |
| 语言 | 中文 / English 随你 | 桌面菜单、托盘会跟着变 |
| 通知 | 开（每日概览） | 只在有到期任务时提醒，不打扰 |
| 同步 | 有第二台设备就开 | 手机记、电脑做才顺畅 |
| 自动备份 | 桌面保持开启 | 误删/迁移的兜底 |

> 关于小米/红米大字体：本 App 的正文不随系统字体缩放，把系统字体调到最大也不会把布局撑乱——这是刻意做的（任务列表最怕错行）。

## 6. 常见问题（FAQ）

**Q1：需要注册账号吗？数据存在哪？**
不需要。数据存在你设备本地的 SQLite 数据库里，没有官方服务器，也不上传任何数据。同步是你自己选的网盘/自建服务。

**Q2：卸载 App 数据会没吗？**
会。卸载前请先导出 JSON，或确认同步/备份已生效。

**Q3：误删了任务怎么办？**
先看回收站（更多 → 清理 → 回收站），能恢复；刚删的还可以 `Ctrl+Z` 撤销。回收站里超过 90 天的删除记录会被清理。

**Q4：两台设备都改了同一条，听谁的？**
改得晚的那次生效（按修订号，不看手机时间）。冲突会记在同步日志里，可在更多 → 同步查看。

**Q5：为什么任务在收集箱里看不到？**
可能被「推迟」到了以后（右滑或动作面板里延后）。到时间它会自动出现；也可以在任务详情里把推迟时间清掉。

**Q6：为什么我设的重复任务完成后没进「已完成」？**
重复任务的语义是「下一次继续」，完成时会把到期日推进到下一次，并记录完成时间；只有次数用完或超过截止日期才会真正结束。

**Q7：桌面端关窗口就退出了？**
点关闭是**最小化到托盘**；要退出用菜单「退出」或托盘右键退出。

**Q8：macOS 打不开？**
安装包未签名/未公证，首次请右键 → 打开；或在「系统设置 → 隐私与安全性」里允许。

**Q9：iOS 能装吗？**
有未签名 IPA，需要自签或 TrollStore 侧载，普通用户不建议折腾。

**Q10：能多人共享清单吗？**
不能。同步是「一个人多台设备」，不是协作。

## 7. 新手 7 天路线（可选）

| 天 | 只做一件事 |
|---|---|
| 第 1 天 | 装好，随手记 10 条，不理清 |
| 第 2 天 | 用「理清」处理掉这 10 条 |
| 第 3 天 | 建 1 个项目，把相关的 3 条任务挂进去 |
| 第 4 天 | 给 3 条任务加到期日，体验「今天」 |
| 第 5 天 | 用一次番茄钟（专注页） |
| 第 6 天 | 配好同步或做一次导出备份 |
| 第 7 天 | 走一遍「每周回顾」，看看统计面板 |

七天之后，你会知道自己适合「重收集」还是「重回顾」，再决定要不要用模板、四象限这些进阶功能。
