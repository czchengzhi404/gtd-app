# v2.7.21 · 《纸与当下》第一轮评审精修

## 独立评审（6/10）

起了一个**全新上下文**的评审者，只给 4 张截图 + 用户/主任务 + 审美 brief，
不给代码、不给历史、不给评分目标。它挑出的三个问题：

1. **NOW 被装进卡片，「唯一笔迹 / 唯一主按钮」没守住** — 大白圆角卡占 60% 视觉，
   顶部还有更大的赭石 `Process`，`3 left today` 也用赭色，赭石不再等于「当下」。
2. **全部页翻页后换了整套视觉语言** — 第二只描边胶囊、白色面板、逐行复选框+分隔线，
   中文字体也变了，「一支笔写到底」的信任感中断。
3. **全局壳把「现在」拉回「收件箱管理」** — 标题 `Inbox / 3 to process`、
   五项底栏、红色角标、黑色完成横条；窄屏截图像素尺寸相同，重排未验证。

## 这一轮改了什么（只改前两处的一部分，不贪多）

### ① NOW 去卡片化
- 去掉白底与 1px 描边，**任务直接落在暖白纸面上**
- 加一道 38×3 的短赭石笔迹作为「现在」的标记（替代整块白卡）
- 主标题 32 → **38px**，行距 48，字距 -0.4
- `Done` 从右下角移到标题下方左侧，与任务贴在一起
- 卡内 240px 固定高度删掉，中间那块「容器空」消失

### ② 唯一实心按钮
- `Process` 在「一张」视角下 `variant="ghost"`，降为文字入口
- `3 left today` 从赭色改回灰（计数只保留一处）
- 现在整屏**只有一个赭色实心按钮 = Done**

### ③ 首屏语义
- 标题 `Inbox / 3 to process` → **`现在` / `Now`**，副标题移除
- 「全部」视角仍保持原来的标题与 Process 实心按钮（不破坏既有操作）

### 装订线
- `bottom: 8` → `bottom: 0`，贯穿到内容末端，不再像局部引导线

## 明确没做的（如实报告）

- **全部页的视觉语言统一**（评审第 2 条）：要重做 `TaskList` 的行样式、字体、
  去掉逐行描边，工作量大且会牵动 8 个页面，留到下一轮或单独发版。
- **底栏收至 2–3 项、红角标、黑色完成横条**（评审第 3 条）：底栏是全局导航，
  改动会超出「首屏重设计」的范围；横条来自 `showUndo` 组件，属另一处。
- **窄屏**：截图脚本用 `wm density 420` 但输出仍是 1080×2400，
  这一项**评审判定为未验证**，我不假称已验证。
