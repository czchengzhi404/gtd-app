# v2.5.2 · 手机上能开同步了

## 修复：Android 明文 HTTP 被拦截

**这是「同步只有电脑端能用」的真正原因。**

Android 9（API 28）起默认禁止明文 HTTP，而桌面端（Electron）没有这个限制。所以在手机上填 `http://` 的自托管 WebDAV / 局域网地址会直接失败——错误通常只显示「网络错误」，看不出是被系统拦了。

修复：加了一个 config plugin，在 AndroidManifest 里显式设 `android:usesCleartextTraffic="true"`；iOS 同步放开 ATS（`NSAllowsArbitraryLoads`）。

> 安全说明：这属于安全降级（同一网络下明文可被嗅探）。因为同步目标是用户自建的网盘/服务器，且默认推荐的坚果云就是 https，所以接受该取舍。设置页会对 `http://` 地址显示警告，建议优先用 https。

**注意**：坚果云、阿里云 OSS 等 https 服务本来就正常，不受此问题影响。受影响的是自托管 HTTP / 局域网 WebDAV。

## 改进：同步独立成页

原先同步配置是「更多」页的**第 5 个分组**、且**默认折叠**——手机上要滚过四组才看得到，很容易误以为「手机没有同步功能」。

现在：

- 「更多」页**最顶部**有「同步」入口（带状态与上次同步时间）
- 点进去是独立的同步页，按三步组织：**① 选方式 → ② 填账号 → ③ 启用并保存**
- 「启用」改成明确的开关行（原来是三个控件挤在一行里的小胶囊）
- 三个按钮改成整行大按钮：保存配置 / 测试连接 / 立即同步
- 页首说明「手机和电脑都支持，只有本地文件夹限定桌面端」

## 手机端怎么配（坚果云为例）

1. 更多 → 同步
2. 方式选「坚果云」（地址已预填 `https://dav.jianguoyun.com/dav/`）
3. 用户名填坚果云账号（邮箱）
4. 密码填**应用密码**——不是登录密码。网页版 → 账户信息 → 安全选项 → 添加应用密码
5. 点「测试连接」，看到成功再往下
6. 打开「同步已启用」开关 → 保存配置
7. 点「立即同步」

另一台设备（电脑）用同一个坚果云账号配置一次，两台就会走同一份数据。
