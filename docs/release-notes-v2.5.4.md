# v2.5.4 · 补齐重复任务与阅读时长

## 本次验证发现的「假已实现」

在手机上逐项验证「已实现但未验证」的功能时，发现两项**功能表里有、UI 上根本没有**：

| 功能 | 原状态 |
|---|---|
| 重复任务（6 种频率） | 只有数据模型和 `nextOccurrence` 算法，**详情页没有任何入口** |
| 看板视图 | `KanbanBoard` 组件存在，**没有任何页面使用它** |

## 修复：重复任务有了 UI

详情页新增「重复」区，六个档位：

- 不重复
- 每天 / 每周 / 每月 / 每工作日
- 完成后（`afterCompletion`，完成后第 N 天再出现）

选中即写入 `recurrence` 字段，走 `task.update` 命令。

## 修复：阅读时长在只读态也显示

原先只有编辑时显示「约 N 分钟读完」，保存后只剩字数。现在只读态显示「N 字 · 约 M 分钟读完」。
