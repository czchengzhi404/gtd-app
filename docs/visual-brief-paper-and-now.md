# 视觉 Brief · 《纸与当下》

> 方向：**C（纸质手账材质）+ A（首屏「现在该做的一件事」）**
> 用户已确认「后者先试试」＝首屏改为「当前一件事 + 后续队列」。
> 强调色用户未指定，我自主拍板：**赭石为主，宝蓝降级为信息/链接色**。
> 理由：蓝在暖白纸底上永远读作「屏幕色」，压不住纸感；赭/墨才像纸上的墨。

## 1. 用户与主任务

用户是「事情很多、注意力有限」的人。主任务不是「管理任务」，而是**在任意时刻回答一个问题：现在该做哪一件**。
次要任务：快速捕捉新事项、按项目/情境归类、回看写过的内容。
典型场景：早上打开 App，不想看 40 条列表，只想看到一件事然后去做。

## 2. 目标感受

安静、笃定、可被信任。像翻开一本用好多年的纸质手账：有使用痕迹但不脏，信息密度低但不空。
明确**不要**：SaaS 仪表盘感、效率工具的紧绷感、激励式彩带与进度庆祝。

## 3. 核心视觉隐喻

**一张摊开的纸 + 一支笔**。
- 页面是纸（暖白 #F7F5F1），不是「容器」
- 唯一强调色是笔迹（赭石），只出现在「当下这一件」和唯一主按钮上
- 左侧一条竖向脊线 = 装订线 / 页边线，任务挂在脊上
- 完成一件事 = 把这一行划掉、下一行浮上来（不是卡片弹飞）

## 4. 构图与信息层级

```
┌ 11月13日 · 周四 ─────────────── 今天还剩 4 件 ┐   ← 页眉，极小字，赭色数字
│                                                │
│  ┃  现在                                       │   ← 装订线 + 分节标（小号大写）
│  ┃  ┌──────────────────────────────────────┐  │
│  ┃  │  预约体检                              │  │   ← 28px 标题，占视觉 60%
│  ┃  │  今天 18:00 · 装修                     │  │
│  ┃  │                          [ 完成 ○ ]    │  │   ← 唯一实心按钮
│  ┃  └──────────────────────────────────────┘  │
│  ┃                                            │
│  ┃  之后 · 3 件                                │   ← 灰字，非卡片
│  ┃  · 量书房尺寸                               │
│  ┃  · 回复客户邮件                             │
│  ┃  · 整理桌面                                 │
│  ┃                                            │
│  ┃  [ 查看全部 4 件 ]                          │   ← 文字按钮，降级
└────────────────────────────────────────────────┘
```
层级只靠 **字号与留白**，不靠卡片套卡片。只有「现在这一件」有底和边框。

## 5. 色彩与字体

| token | 亮色 | 说明 |
|---|---|---|
| canvas | `#F7F5F1` | 纸（不变） |
| surface | `#FFFDF9` | 微暖白，比纯白更像纸 |
| primary | `#8C3D0B` | **赭石**（原 `#1D4ED8`），对比度 ≥4.5 |
| primaryMuted | `#F6E9DC` | 赭的极淡底 |
| info | `#1D4ED8` | 宝蓝降级为此，仅链接/信息用 |
| text | `#1A1A18` | 墨（不变） |
| border | `#D8D4CB` | 纸纤维（不变） |

字体：标题用系统字 700 + 字距 -0.3；正文行距 1.7；所有分节标小号大写字距 +1.2。
**不引入新字体文件**（内置 LXGW WenKai 只在用户主动开启时使用，不强制铺满）。
深色模式：primary → `#E0A878`，primaryMuted → `#3A2818`。

## 6. 关键交互

- 完成「现在这一件」→ 该行划掉淡出（220ms，复用已有 LayoutAnimation）→ 下一件从下方浮上来
- 「查看全部」切到原有的完整列表（含搜索/筛选/多选/拖拽），**不删任何既有能力**
- 视角状态本机记住（kv `inbox.focusMode`），默认「一张」
- 快速添加永远在，位置不变（捕捉不能被首屏改造挤掉）
- 减少动效：跟随系统 `AccessibilityInfo.isReduceMotionEnabled()`

## 7. 要避免的元素

- 渐变、发光、玻璃拟态、阴影堆叠
- 每张卡片都带描边（只有当前卡有）
- emoji、励志文案、彩带/粒子庆祝
- 超过两级的信息嵌套
- 把「之后」也做成卡片（那会重新变成 40 条列表）

## 8. 第一版最小范围

只做三个文件 + 一个新组件，**不动其它 7 个页面**：
1. `packages/ui/src/theme/tokens.ts` — 颜色 token
2. `packages/core/src/features/next-action.ts` — `pickNextAction()` 纯函数 + 单测
3. `packages/ui/src/components/NowView.tsx` — 首屏新组件（含一张/全部切换）
4. `apps/mobile/src/app/(tabs)/index.tsx` — 接入

验收：能跑、能截图；「一张」和「全部」两态都可操作；完成一件后队列前移；既有筛选/多选/拖拽不回归。
