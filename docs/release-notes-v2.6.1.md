# v2.6.1 · 项目类型可切换

## 新增

项目详情里的类型胶囊（`Sequential` / `Parallel`）现在**可以点**，点了在两种类型间切换，立即写入 `project.kind`。

- **顺序（sequential）**：一次只推进一件事，完成当前任务后下一个才成为「下一步行动」
- **并行（parallel）**：多个任务可同时推进

无障碍标签：「切换项目类型（顺序 / 并行）」。

## 背景

这是上一轮测试自己找出来的：数据层 `project.upsert` 早就支持 `kind`，UI 却只把它渲染成一个只读的 `<View>` 标签。典型的「假已实现」——功能表里打了勾，实际点不动。

## 明确不做的功能

**外接键盘快捷键** —— 已确认不做（2026-11-08）。

原因：React Native 移动端没有全局键盘事件 API，只能监听 TextInput 内部的按键，做不出桌面那种全局 `Ctrl+K`。要么引原生模块（又一次无法本地验证的原生依赖），要么不做。手机外接键盘的使用场景极少，收益不抵风险。

这个决定已记入 `docs/mobile-feature-matrix.md`，后续不再提起。
