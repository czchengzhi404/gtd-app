# v2.5.5 · 移动端补上备份、检查更新、看板

## 新增：移动端本地备份

之前移动端点「备份」只提示「备份仅在桌面端可用」。现在可用：

- 备份位置：应用文档目录 `backups/`，保留最近 **7** 份
- 关键细节：**先 `PRAGMA wal_checkpoint(TRUNCATE)` 再复制**。库开了 WAL，最新写入可能还在 `-wal` 文件里，只复制 `gtd.db` 会拿到旧数据
- 路径不硬编码：用 `PRAGMA database_list` 向 SQLite 要真实文件路径
- 恢复：复制回主库并删除 `-wal`/`-shm`（否则会与新主库不一致），**需要重启应用生效**

## 新增：检查更新

移动端侧载 APK 没有桌面那种自动更新。等价物是：关于页 → 检查更新 → 查 GitHub 最新 release → 比较版本 → 有新版就显示「去下载」。

不做静默安装：侧载应用的静默安装会触发系统安全策略。
